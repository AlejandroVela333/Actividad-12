# ChuckJokesVue

## Activity 12

ChuckJokesVue is a small Vue 2 application that displays the five Chuck Norris phrases provided in Activity 12.

## Objective

The activity practices the creation of a Vue instance, the definition of reactive `data`, declarative rendering with `v-for`, and basic presentation with CSS.

## Technologies

- HTML5
- CSS3
- JavaScript
- Vue 2 via CDN

## Project structure

- `index.html`: contains the application container and the list rendered with `v-for`.
- `main.js`: creates the Vue instance and defines the `chuck` data array.
- `style.css`: provides the minimal, responsive visual design.
- `docs/`: contains the activity report and real evidence screenshots.

## How to run

Open `index.html` directly in a browser, or serve the project folder with a local web server such as Live Server.

The application loads Vue 2 from:

```text
https://cdn.jsdelivr.net/npm/vue/dist/vue.js
```

An Internet connection is required when the browser does not already have the CDN resource cached.
